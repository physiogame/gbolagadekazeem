GBOLAGADE GITHUB PAGES REDIRECT

This pack sends visitors from your old GitHub Pages portfolio to:

https://gbolagadekazeem.web.app

HOW TO USE IT

1. Open the GitHub repository that publishes:
   https://physiogame.github.io/gbolagadekazeem

2. Replace the old index.html file with the index.html file in this pack.

3. Add the 404.html file to the same main folder.

4. Commit the changes to the branch used by GitHub Pages.

5. Wait one or two minutes, then visit the old address in a private browser window.

The index.html file redirects the main address. The 404.html file also redirects people who open an old page or broken link inside the former portfolio.
